To enable plugins in RusherHack 2.0:

Add the JVM flag -Drusherhack.enablePlugins=true to your Minecraft JVM arguments.
Create the directory .minecraft/rusherhack/plugins/ in your Minecraft folder.
To install plugins:

Download the desired plugin(s) .jar files from their respective repositories.
Place the .jar files in the .minecraft/rusherhack/plugins/ directory.
Launch the game with the plugin
Now you can see the capes folder on minecraft\rusherhack\capes
Drop the capes png to the minecraft\rusherhack\capes
 
Do *cape reload
